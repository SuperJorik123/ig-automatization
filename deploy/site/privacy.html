Privacy Policy

News-automation · Last updated: 28 September 2026

News-automation (“we”, “us”) is a private publishing tool. It publishes news videos and photos to social media accounts that we own and operate, on Instagram, YouTube, X (Twitter) and Telegram. It is not a consumer service: members of the public do not sign up for it, log in to it or use it directly. This policy explains what data the tool handles and how to have data deleted.

1. Data we collect #

When one of our own Instagram accounts is connected through Instagram Login, the tool receives and stores only:

  • the account’s Instagram user ID and username;
  • the access token Instagram issues for that account, which the tool refreshes periodically so it keeps working.

We do not collect followers’ data, comments, direct messages, contact lists, location data, or any information about people who view or interact with our posts. We do not use cookies or analytics on this website.

2. How we use it #

The account ID and access token are used for one purpose: publishing photos and reels to that same account through the Instagram Graph API. Media being published is placed at a temporary, unguessable web address for the few seconds Instagram needs to fetch it and is deleted immediately afterwards.

3. Sharing #

We do not sell, rent or share this data with anyone. It is sent only to the platform it belongs to (for example, an Instagram token is sent only to Instagram) in order to publish content.

4. Storage and retention #

Credentials are stored on a private server with access restricted to the operator. They are kept only while the account is connected to the tool and are deleted when the account is disconnected or a deletion request is received (see User data deletion).

5. Third-party platforms #

Content published by the tool is subject to each platform’s own privacy policy: Instagram / Meta, Google (YouTube), X and Telegram. The YouTube upload feature uses YouTube API Services and is bound by the YouTube Terms of Service.

Google user data. For YouTube the tool requests only the scope https://www.googleapis.com/auth/youtube.upload and uses it only to upload video files to the authorising account’s own YouTube channel. The resulting OAuth token is stored on the operator’s own server and is never transmitted to, shared with, or sold to any third party. No other Google user data is requested, accessed, stored or processed. Access can be revoked at any time at myaccount.google.com/permissions.

6. User data deletion #

You can ask us to delete any data associated with your account at any time. Two ways:

  1. Remove the app from Instagram. In the Instagram app, go to Settings → Website permissions → Apps and websites, select News-automation and tap Remove. This revokes the access token immediately; we then delete the stored account ID and token.
  2. Email us. Send a message to victorbaxan111@gmail.com with the subject “Data deletion request” and the Instagram username concerned.
We delete the account ID, username and access token within 30 days of the request and reply by email to confirm once it is done. Posts already published on your account are content on Instagram and can be removed by you directly in the app.

7. Contact #

Questions about this policy: victorbaxan111@gmail.com. If this policy changes, the date at the top of this page is updated.
