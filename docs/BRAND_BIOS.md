# Brand bios (Instagram / Facebook)

Decided with the owner, 2026-11-17. Each brand's caption voice (`writing_style` in
`brands/<group>/<name>/style.json`) is to be rewritten to match its bio — not done yet.

Pattern every tagline follows (taken from Frontiva's, the one that works):
**echo the account name + a role + an enemy/mission**. No "Follow …" call to action in
the bio. The search keyword goes in the Name field (Instagram search reads it); the
bio itself stays short and punchy.

Audience for every account: **US**, English. Content is **global** viral news (there
aren't enough US clips), so no bio promises "US news" — the US targeting comes from
posting at US evening time, English, and preferring US stories / clips without
non-English speech when there's a choice. (Owner's correction, 2026-11-17.)

## What the caption voice has to keep true

- **Frontiva** — every reel must survive a fact-check; never post an unverified claim as fact.
- **WS Wire** — independent, slightly defiant tone ("can't cut", "unfiltered"); leans
  anti-establishment, so watch that it doesn't drift into partisan politics.
- **Atlas** — the overlooked story: always name the town/state, and favour stories the
  big networks skipped.
- **Eur24news** — the European angle for a US viewer: European clips go here first, and
  the caption explains the European context an American wouldn't know.
